# NAYAN NANDY — Website Design 2

This is the second website concept for NAYAN NANDY — Global Agri Trade. It is a self-contained static website with its first featured product as **Non-Basmati Indian White Rice** and its second as **De-Oiled Rice Bran**.

## Publish on GitHub Pages

1. Create a public GitHub repository such as `nayan-nandy-design-2`.
2. Extract this ZIP and upload its **contents** to the repository root. Keep `index.html`, `main.css`, `app.js`, and the entire `assets` folder together.
3. Commit the files to `main`.
4. Go to **Settings → Pages → Build and deployment → Deploy from a branch**. Select `main` and `/(root)` and save.
5. Once published, visit `https://YOUR-USERNAME.github.io/nayan-nandy-design-2/`.

This package uses relative asset paths, so it works in a GitHub Pages repository subdirectory or a custom-domain root.
